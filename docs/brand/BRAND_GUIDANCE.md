# 🎨 Comunity - Brand Guidance

## 1. IDENTIDAD DE MARCA

### Misión
Conectar personas en su comunidad local para transacciones económicas inmediatas dentro de un radio de 5km.

### Visión
Ser la plataforma de referencia para la economía local en tiempo real en toda América Latina.

### Valores
- **Local First**: Enfoque en comunidades, no corporaciones
- **Real Time**: Transacciones inmediatas, sin demoras
- **Trust**: Reputación basada en acciones reales
- **Inclusive**: Accesible para todos, todos pueden vender
- **Sustainable**: Economía local = comunidades fuertes

### 2.3 Tipografía

```

  Weight: 600-700 (Bold)
  Size: 16-32px
  Uso: H1, H2, H3, nombres de usuario
```

## 5. TONO Y VOISC

### 5.1 Principios

```
- Amigable pero profesional
- Directo y claro
- Inclusivo (accesible)
- Energético pero no invasivo
- Local (usar términos de la comunidad)
```

### 5.2 Ejemplos

#### ✅ Correcto
- "¡Anunciar en 5km a la redonda!"
- "Contactar ahora"
- "Tu oferta está visible para 12 personas"
- "Doña Carmen vende tamales caseros a $50/docena"

#### ❌ Incorrecto
- "Proceder al listado de productos"
- "Implementar solicitud"
- "Aplicación iniciada"
- "Elemento 234 de categoría X"

### 5.3 Mensajes Comunes

```
Bienvenida:
  "¡Bienvenido a Comunity! Aquí encuentras todo lo que necesitas en tu área."

Error:
  "Algo salió mal. Intenta de nuevo."

Éxito:
  "¡Perfecto! Tu anuncio está visible para [X] personas."

Confirmación:
  "¿Estás seguro que quieres [acción]?"

Vacío:
  "Aquí aparecerán tus [items]. ¡Empieza a explorar!"

Loading:
  "Cargando..."
```

## 6. ESCRITURA Y REDACCIÓN

### 6.1 Style Guide

```
Mayúsculas: Título Case para títulos
Puntuación: Punto al final de oraciones
Emojis: Sí, pero con moderación (máximo 1 por sección)
Acrónimos: Explica la primera vez (ej: 5km = cinco kilómetros)
Genérico: Usa lenguaje inclusive
Tiempos: Presente para acciones
```

### 6.2 Palabras Clave

```
Use (Sí):          Avoid (No):
---                ---
Anunciar           Publicar
Contactar          Mensaje
Cercano            Distancia
Oferta             Producto
Transacción        Operación
Reputación         Puntuación
Comunidad          Grupo
Local              Regional
Inmediato          Rápido
Verifica           Comprueba
```

## 8. MOTION Y ANIMATION

### 8.1 Transiciones

```
Rápido:     0.2s (hover, pequeños cambios)
Normal:     0.3s (cambios medianos)
Lento:      0.5s (grandes transiciones)

Easing:     ease-out (natural, no mecánico)
Timing:     cubic-bezier(0.4, 0, 0.2, 1)
```

### 8.2 Animaciones

```
Pulse (para elementos en vivo):
  @keyframes pulse {
    0%, 100% { opacity: 1; transform: scale(1); }
    50% { opacity: 0.5; transform: scale(1.05); }
  }

Fade:
  opacity: 0 → 1

Slide:
  transform: translateY(-4px) on hover
```

## 9. ACCESIBILIDAD

### 9.1 Colores

```
✅ Contraste mínimo: 4.5:1 para texto
✅ No usar color solo (agregar iconos/textos)
✅ Evitar rojo + verde solo
✅ Test con simuladores de daltonismo
```

### 9.2 Texto

```
✅ Línea: máximo 60-80 caracteres
✅ Espaciado: mínimo 1.5x tamaño de letra
✅ Fuente: Clara y legible (no cursiva)
✅ Tamaño: mínimo 12px en mobile
```

### 9.3 Interactividad

```
✅ Estados claros (hover, active, disabled)
✅ Labels en inputs
✅ Alt text en imágenes
✅ ARIA labels donde sea necesario
```

## 11. DO's AND DON'Ts

### DO ✅
- Usa el cian y verde en CTAs
- Mantén consistencia en espaciado
- Usa títulos claros
- Muestra la comunidad local
- Sé directo y claro
- Incluye emojis relevantes

### DON'T ❌
- No mezcles colores aleatorios
- No uses fuentes extrañas
- No ocultes información
- No uses stock photos falsos
- No hagas copywriting corporativo
- No exageres con animaciones
